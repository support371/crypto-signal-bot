CryptoOps Custom GPT Privacy Policy

Last updated: July 17, 2026.

Purpose

The CryptoOps Custom GPT provides read-only operational visibility for the support371/crypto-signal-bot project. Its published Action schemas do not expose order placement, withdrawals, deployments, Guardian resets, configuration changes, or repository writes.

Data processed

When an authorized user invokes an Action, the selected provider may return operational metadata such as health status, readiness checks, pull-request metadata, commit checks, deployment status, and infrastructure inventory. The GPT should request only the information needed for the current operational question.

Credentials

Provider credentials are configured separately in the Custom GPT Action settings. Credentials must not be placed in the OpenAPI files, repository, prompts, logs, browser storage, or responses. The GPT must not reveal bearer tokens, API keys, exchange credentials, private keys, signed URLs, or secret environment values.

Financial data

The Actions are intended for operational evidence and do not authorize financial execution. The GPT must not place or cancel orders, move funds, approve withdrawals, or activate live trading.

Storage

This repository does not intentionally store Action credentials or identity documents. Provider systems and the ChatGPT product may process requests according to their own applicable policies and account settings.

Sharing and sale

Project data is not sold to advertisers. Operational data should be shared only with authorized project participants and only to the extent necessary for project operations and review.

Retention and deletion

Repository content follows the project’s Git history and retention practices. Provider-side logs and ChatGPT conversation retention are controlled through the relevant provider and product settings.

Security

Use least-privilege, read-only provider tokens. Rotate compromised credentials immediately. Do not use a token that can write repository state, deploy infrastructure, alter Cloudflare resources, change Vercel configuration, or access exchange trading or withdrawal functions.

Contact

Questions about this project policy should be raised through the repository’s normal issue or security-reporting process without including secrets.
